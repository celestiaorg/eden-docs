# Bridging

Use [Eden Zone](https://eden.zone/) to bridge assets to Eden.

:::info
Eden bridging uses Hyperlane routes. This page covers the public bridge experience and avoids
operational deployment details.
:::

Check [Eden Zone](https://eden.zone/) for the assets and routes currently available before
starting a transfer.

## Manual transfers

Most users should use [Eden Zone](https://eden.zone/). If you need to bridge manually with CLI
tools, use `celestia-appd` and `cast` with the current Hyperlane route configuration.

Manual bridging requires converting recipient addresses into the format expected by the route
contract and paying the required interchain gas. Validate the latest route parameters before
broadcasting transactions.
