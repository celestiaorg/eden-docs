# Contact Eden

## Developer questions

Join the [Celestia community on Telegram](https://t.me/celestiacommunity) for
questions about building on Eden. Include the network, tool version, command,
and relevant error message so others can understand the issue. Remove secrets
and personal information before sharing logs. There is no general support email
published for these docs.

## Documentation corrections

Report broken examples, missing information, or incorrect links in the
[Eden documentation issue tracker](https://github.com/celestiaorg/eden-docs/issues).
Include the affected page URL and what you expected to happen. You can also use
any page's edit link to propose a documentation change.

## Security disclosures

Follow the [Celestia security policy](https://github.com/celestiaorg/.github/blob/main/SECURITY.md).
Report a vulnerability privately through the affected repository's Security tab.
If private reporting is unavailable, email [security@celestia.org](mailto:security@celestia.org).
This address is for security disclosures, not general developer support.
Do not post vulnerability details in public issues or community chats.

Never share wallet recovery phrases, private keys, API keys, or `.env` files in
support requests. See the [privacy information](/privacy) for further guidance.
