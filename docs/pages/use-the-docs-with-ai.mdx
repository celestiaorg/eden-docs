# Use Eden docs with AI

Eden publishes a public, read-only Model Context Protocol server for these docs.
Add it to your coding agent to search the docs, read pages as Markdown, and keep
Eden network and tooling details close at hand while you build.

| Property  | Value                                    |
| --------- | ---------------------------------------- |
| Name      | `eden-docs`                              |
| URL       | `https://docs.eden.zone/api/mcp`         |
| Transport | Streamable HTTP                          |
| Tools     | `list_pages`, `read_page`, `search_docs` |

:::info
The documentation REST API and MCP server are public and read-only. They require
no account, agent registration, OAuth token, or API key. This applies to the
documentation service; blockchain RPC providers have separate access rules.
Never send a wallet recovery phrase, private key, or `.env` file.
:::

## Read without an MCP client

Start with the page index at `/llms.txt`, complete documentation at `/llms-full.txt`,
or agent guidance at `/AGENTS.md`. Each page is also available as Markdown: append
`.md` to its path, or request the page with `Accept: text/markdown`.

```bash
curl -L -H 'Accept: text/markdown' https://docs.eden.zone/networks/mainnet
```

MCP clients can discover connection details through the server card at
`/api/mcp/server-card`. Connect to `/api/mcp` to list and call tools.

## Search from a browser agent

Browsers with [WebMCP](https://webmachinelearning.github.io/webmcp/) support can
discover `search_eden_docs` when any documentation page loads. Pass a non-empty
`query` string to search the docs and receive matching page paths and snippets.
The tool uses the public [documentation REST API](/api-reference); it requires
no account, credentials, or wallet access.

WebMCP is an experimental browser API. In browsers without support, use the MCP
server, REST API, or Markdown pages described above.

## Agent skills and API discovery

The Eden development skill guides agents to current network settings and the
relevant contract, frontend, transaction, and token documentation. Tools can
discover it through `/.well-known/agent-skills/index.json`, which includes the
skill's URL and a SHA-256 digest to verify the download.

The OpenAPI description at `/openapi.json` documents the [REST API](/api-reference)
and the MCP endpoint's JSON-RPC requests and responses. It describes the documentation server; Eden's
chain RPC endpoints are listed on the network reference pages.
The API catalog at `/.well-known/api-catalog` links to this description and setup
guide. The AI catalog at `/.well-known/ai-catalog.json` lists the MCP server, skill
index, and documentation index.

Malformed requests return JSON-RPC errors. A tool call must include its required
arguments: `pagePath` for `read_page`, or a non-empty `query` for `search_docs`.
When a page is missing, `read_page` returns a tool result with `isError: true`;
use `list_pages` to choose a current path. Send one JSON-RPC message per POST.

## Errors and recovery

All errors generated by the documentation API under `/api` use JSON. The
[REST reference](/api-reference#errors-and-recovery) covers `/api/v1` errors. Unknown
API paths return HTTP 404; unsupported methods return HTTP 405 with an `Allow`
header. These HTTP errors contain `error.code`, `error.message`, and `error.hint`.
In particular, `GET /api/mcp` returns 405 because this server does not offer an
SSE stream. Use `POST /api/mcp` for JSON-RPC, or `GET /api/mcp/server-card` for
connection details.

JSON-RPC errors preserve numeric protocol codes and include a recovery hint in
`error.data.hint`. Parse errors and invalid requests return HTTP 400. Unknown
methods, invalid tool arguments, and internal documentation failures return an
error under HTTP 200, so check the body as well as the status. A missing page
remains an MCP tool result with `isError: true`.

## Versioning and deprecation

During `initialize`, request an MCP protocol version and read the negotiated
`protocolVersion` in the response. Send that value as `MCP-Protocol-Version` on
subsequent requests. The [OpenAPI description](https://docs.eden.zone/openapi.json) and
[server card](https://docs.eden.zone/api/mcp/server-card) list the supported versions. Unsupported
version headers receive HTTP 400; an omitted header defaults to `2025-03-26`.

The server currently advertises no deprecated protocol version and sends no
`Deprecation` or `Sunset` headers. There is no published minimum notice period
for retiring a version. Check the supported versions when connecting; do not
interpret the OpenAPI document version as a blockchain RPC version or a support
guarantee. Changes can be reviewed in the
[documentation repository](https://github.com/celestiaorg/eden-docs).

## Rate limits

The documentation server does not currently advertise a fixed request quota or
emit `RateLimit` headers. Blockchain RPC provider limits are separate; consult
the [mainnet](/networks/mainnet) or [testnet](/networks/testnet) reference.

If a hosting or upstream service responds with HTTP 429, respect its
`Retry-After` header when present; otherwise reduce concurrency and retry with
backoff. Cache documentation reads when possible. Edge-generated errors may
have a different format from the JSON errors generated by this server.

## Codex

```bash
codex mcp add eden-docs --url https://docs.eden.zone/api/mcp
```

Codex stores MCP servers in `~/.codex/config.toml`. To configure the server by
hand, add:

```toml
[mcp_servers."eden-docs"]
url = "https://docs.eden.zone/api/mcp"
```

Inside Codex, run `/mcp` to confirm the server is connected.

## Claude Code

```bash
claude mcp add --transport http eden-docs https://docs.eden.zone/api/mcp
```

Inside Claude Code, run `/mcp` to confirm the server is connected.

## Cursor

Add this to `.cursor/mcp.json` for this project, or to `~/.cursor/mcp.json` to
use it everywhere:

```json
{
  "mcpServers": {
    "eden-docs": {
      "url": "https://docs.eden.zone/api/mcp"
    }
  }
}
```

## VS Code / GitHub Copilot

Add this to `.vscode/mcp.json` for this workspace, or to your user MCP config:

```json
{
  "servers": {
    "eden-docs": {
      "type": "http",
      "url": "https://docs.eden.zone/api/mcp"
    }
  }
}
```

## Windsurf / Cascade

Add this to `~/.codeium/windsurf/mcp_config.json`:

```json
{
  "mcpServers": {
    "eden-docs": {
      "serverUrl": "https://docs.eden.zone/api/mcp"
    }
  }
}
```

## Try it

After connecting the server, ask your agent:

```text
Search the Eden docs for the mainnet RPC URL and block explorer.
```
