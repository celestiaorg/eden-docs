# Use the docs with AI

Eden publishes a public, read-only Model Context Protocol server for these docs.
Add it to your coding agent to search the docs, read pages as Markdown, and keep
Eden network and tooling details close at hand while you build.

| Property  | Value                                    |
| --------- | ---------------------------------------- |
| Name      | `eden-docs`                              |
| URL       | `https://docs.eden.zone/api/mcp`         |
| Transport | Streamable HTTP                          |
| Tools     | `list_pages`, `read_page`, `search_docs` |

:::info
The docs MCP server is public and read-only. It never needs a wallet recovery
phrase, private key, API key, or `.env` file.
:::

## Read without an MCP client

Start with the page index at `/llms.txt`, complete documentation at `/llms-full.txt`,
or agent guidance at `/AGENTS.md`. Each page is also available as Markdown: append
`.md` to its path, or request the page with `Accept: text/markdown`.

```bash
curl -L -H 'Accept: text/markdown' https://docs.eden.zone/networks/mainnet
```

MCP clients can discover connection details through the server card at
`/api/mcp/server-card`. Connect to `/api/mcp` to list and call tools.

## Agent skills and API discovery

The Eden development skill guides agents to current network settings and the
relevant contract, frontend, transaction, and token documentation. Tools can
discover it through `/.well-known/agent-skills/index.json`, which includes the
skill's URL and a SHA-256 digest to verify the download.

The OpenAPI description at `/openapi.json` documents the existing MCP endpoint's
JSON-RPC requests and responses. It describes the documentation server; Eden's
chain RPC endpoints are listed on the network reference pages.
The API catalog at `/.well-known/api-catalog` links to this description and setup
guide. The AI catalog at `/.well-known/ai-catalog.json` lists the MCP server, skill
index, and documentation index.

Malformed requests return JSON-RPC errors. A tool call must include its required
arguments: `pagePath` for `read_page`, or a non-empty `query` for `search_docs`.
When a page is missing, `read_page` returns a tool result with `isError: true`;
use `list_pages` to choose a current path. Send one JSON-RPC message per POST.

## Codex

```bash
codex mcp add eden-docs --url https://docs.eden.zone/api/mcp
```

Codex stores MCP servers in `~/.codex/config.toml`. To configure the server by
hand, add:

```toml
[mcp_servers."eden-docs"]
url = "https://docs.eden.zone/api/mcp"
```

Inside Codex, run `/mcp` to confirm the server is connected.

## Claude Code

```bash
claude mcp add --transport http eden-docs https://docs.eden.zone/api/mcp
```

Inside Claude Code, run `/mcp` to confirm the server is connected.

## Cursor

Add this to `.cursor/mcp.json` for this project, or to `~/.cursor/mcp.json` to
use it everywhere:

```json
{
  "mcpServers": {
    "eden-docs": {
      "url": "https://docs.eden.zone/api/mcp"
    }
  }
}
```

## VS Code / GitHub Copilot

Add this to `.vscode/mcp.json` for this workspace, or to your user MCP config:

```json
{
  "servers": {
    "eden-docs": {
      "type": "http",
      "url": "https://docs.eden.zone/api/mcp"
    }
  }
}
```

## Windsurf / Cascade

Add this to `~/.codeium/windsurf/mcp_config.json`:

```json
{
  "mcpServers": {
    "eden-docs": {
      "serverUrl": "https://docs.eden.zone/api/mcp"
    }
  }
}
```

## Try it

After connecting the server, ask your agent:

```text
Search the Eden docs for the mainnet RPC URL and block explorer.
```
