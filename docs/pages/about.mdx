# About Eden

Eden is an EVM network built using the [Evolve stack](https://github.com/evstack)
and powered by Celestia for data availability. It runs its own execution environment:
applications deploy Solidity contracts and connect through EVM-compatible tools.
[Why Eden](/why-eden) describes the network's application development features.

These public developer docs cover network connections, contract deployment,
frontend integrations, tokens, and node operation. The [developer portal](/developers)
links to quickstarts and testnet resources. Use the [mainnet](/networks/mainnet)
and [testnet](/networks/testnet) references for current connection settings.

The [documentation source](https://github.com/celestiaorg/eden-docs) is public.
You can report documentation issues or propose corrections there. For community
questions and private security reporting, use the channels on the [contact page](/contact).

The [disclaimer](/legal/disclaimer) identifies Celestia Labs (Monoma Ltd.) and
explains the scope and limitations of these materials. The [privacy page](/privacy)
links to Celestia's published privacy policy.
