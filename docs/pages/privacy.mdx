# Privacy policy

The [Celestia privacy policy](https://celestia.org/privacy/) applies to Eden docs.
Read that policy for details about personal information and how to contact Celestia
about privacy. The linked policy is the authoritative text; this page provides a
stable place to find it from the documentation.

## Using these docs

You can read the documentation and use its public MCP server without creating an
account or supplying an API key. The MCP server accepts documentation search
queries and page paths. Do not include wallet recovery phrases, private keys,
API keys, or other confidential information in those requests.

Links to blockchain RPC providers, explorers, wallets, and community platforms
lead to separate services. Review the privacy information for each service you
choose to use. For community help or a documentation correction, see the
[contact page](/contact).
